# Workflow

## System Flow

1. User enters elderly citizen information through the input form.
2. Data is automatically stored in Google Sheets.
3. Dashboard updates and displays summary information.
4. Users can export reports as PDF or Excel files.
5. Generated reports are used for administrative documentation and reporting.

---

## Main Purpose

- Reduce manual paperwork
- Improve data organization
- Simplify report generation
- Support administrative operations
